    Backwork (backwork v0.1.0)

    Copy Markdown View Source

    One-call OpenTelemetry tracing for backwork.dev.

    There are two pieces — one boot-time, one runtime:

    1. Exporter config (boot-time) in config/runtime.exs:

      config :opentelemetry, traces_exporter: :otlp
config :opentelemetry_exporter, Backwork.exporter_config()

    2. Instrumentation (runtime) in your Application.start/2, before the supervisor children start:

      Backwork.setup(phoenix_adapter: :bandit, ecto: [[:my_app, :repo]])

    Set BACKWORK_TOKEN to your project's ingest token, and optionally OTEL_RESOURCE_ATTRIBUTES=service.name=my-app so it's named in backwork.

    Logs and host/container metrics come from the backwork agent — this package is only for distributed traces / APM.
